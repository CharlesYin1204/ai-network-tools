# 询赋 UI 设计
方向：熟人网络中的资源发现。像一个可以邀请同行坐下聊聊的数字空间；清晰、通透、有温度。以资源摄影和关系线条为主视觉，不用抽象科技光球。
色板：纸白 #ffffff、雾灰 #f5f7f8、深松 #173c35、询赋绿 #167557、薄荷 #e2f2e9、AI 紫 #7361c9。
字体：中文系统 PingFang SC / Microsoft YaHei，拉丁 Arial。正文14–16px，标题32–58px，数字28px。
首页：顶栏 + 左导航；内容顶部左侧文案和右侧资源照片拼贴；下方搜索和分类，再是有信息密度的资源网格、右侧轻量关系推荐。移动端单列与固定底部5项菜单。
用户中心：一屏展示名片、人脉、资源、需求、匹配、收藏、消息、AI记录、通知与账户；业务入口不得藏在说明文本中。
管理后台：独立深绿导航，白色操作表格，重点明确状态、审核与模型测试；APK配置/构建/上传/记录放同页。
评审调整：官网证实产品是熟人价值社交，主导航从纯“资源商城”改为“发现/机域/人脉/小赋AI”，资源价钱弱化为合作方式；主视觉展示空间、专业技能、设备三类真实资源，不渲染成二手交易平台。
