# 询赋演示平台后端交付说明

验证日期：2026-10-14（Asia/Shanghai）

## 实现

- Next.js App Router + Node.js route handler，入口 `app/api/[...path]/route.js`；MySQL 5.7，数据库 xunfu。
- 账户注册、登录、登出、bcrypt 密码、JWT HttpOnly/SameSite cookie、数据库即时角色/启停校验、写请求同源检查。
- 资源发布、审核、修改、搜索、收藏、公开/好友/二度人脉可见权限；需求发布和关闭；双方撮合状态；联系人请求、星标、隐藏、二度人脉引荐；站内消息及通知。
- 用户名片资料和可见性，管理员统计、用户启停、资源审核、需求/撮合/咨询线索、站点设置。
- AI 模型管理、真实连通测试、AES-256-GCM 密钥加密、默认模型、调用日志、用户隔离的会话历史；小赋聊天、发布文案、供需推荐、资源估值、需求分析、智能找人均调用实际模型。
- Android 配置、构建、上传、构建列表、已验证文件下载 API 已接入。

## 初始数据

- 12 条资源，4 条需求，8 个账号；初始资料明确标注演示数据。
- 演示人脉包含一度与二度关系；隐藏边不进入可见人脉图，隐藏名片不进入 AI 上下文。
- 数据脚本：`scripts/init-db.mjs`；DDL：`database/schema.sql`。

## 凭据与密钥位置

- `.env.local` 保存数据库连接及签名/加密密钥，文件权限 600。
- `data/access.json` 保存管理员与演示账号登录资料，文件权限 600。
- 根目录原始 AI 配置资料文件已收紧至 600。
- 管理员 API 仅返回 `apiKeyMasked`，不返回真实上游密钥。

## 运行检查

```sh
node --env-file=.env.local scripts/init-db.mjs
TEST_BASE_URL=http://127.0.0.1:3050 node --env-file=.env.local scripts/test-api.mjs
node --env-file=.env.local scripts/test-ai.mjs
```

AI 测试会发起真实收费接口调用。默认 API 集成测试地址为 3051，可通过 TEST_BASE_URL 指定部署端口。

## 当前边界

- 此项目是独立面试演示，不代表官方运营系统；不含真实支付、资金托管、实名认证、短信服务或移动端原生即时通讯。
- AI 估值是未经市场验证的参考建议；上游失败返回明确错误，不用伪造答案兜底。
- 站内消息通过页面读取与发送，不含 WebSocket 推送。
- 列表当前使用上限 100–300 条，适合演示；后续规模化可增加游标分页。
- 测试结果验证服务器构建、签名与 HTTP 下载，不代表已在实体 Android 设备上完成端到端安装验证。

## 最终前后端合同与社区扩展（2026-10-14）

已执行两个可重复升级脚本，保留已有用户与业务记录：

- `scripts/migrate-ui-contract.mjs`：统一六类资源、二度名片可见性、需求可见性、运营设置及每日 AI 计数。
- `scripts/migrate-community.mjs`：机域动态/点赞/评论表、隐藏职位字段、资源审核原因，并添加 3 条明确标注的演示动态。

机域支持发布、编辑、关闭、公开/好友/二度范围、点赞与评论；管理员可隐藏/恢复。被管理员隐藏的内容不能由作者自行恢复，非授权用户不能读取或评论。用户个人职位隐藏后，对二度人脉和非好友不返回职位，直接好友仍可见。

管理设置中的 requireReview（布尔或 true/false 字符串）、aiDailyLimit（1–10000 整数）、supportEmail、announcement 均保存并用于实际功能。AI 配额以 Asia/Shanghai 自然日原子计数，避免并发请求越过配额。资源关闭状态和前端 published/active 等值有明确兼容映射。

AI 每次重新计算可见人脉、资源和需求。历史只带最近 5 条用户消息以保留需求澄清；旧 assistant 推荐不会再次发送给模型，系统约束明确历史不是当前访问授权依据。模型输出仍是生成式建议，不宣称具备结构化候选 ID 的最终硬校验。
